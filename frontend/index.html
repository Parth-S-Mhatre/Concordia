DATABASE IMPORT WORKFLOW

From raw upload to unified entity

The same pipeline runs for every source — CSV or SQL — with human review before records are processed.

01 / INGEST

Bring a source in

Upload CSV or SQL dump, including multi-part datasets and multi-table databases. Schema and tables are detected automatically.

02 / MAP

Review field mapping

AI-assisted suggestions map email_id → email, contact_no → phone. Your review is final before processing.

03 / CLEAN

Normalize values

Emails lowercased, phones de-formatted, whitespace collapsed. Raw and normalized values are both preserved.

04 / INDEX

Build lookup indexes

Batch-written email, phone, username, and member-ID indexes keep repeated matching fast at scale.

05 / MATCH

Resolve across sources

Configurable hierarchy — email, phone, username, member ID, then fuzzy rules — links records without duplicating entities.

06 / ENRICH

Grow master profiles

Every new dataset re-checks existing entities, enriches matches, and keeps unmatched records for future matching.
